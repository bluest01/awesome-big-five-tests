# Awesome Big Five & OCEAN Personality Tests

A curated list of free online Big Five (OCEAN) personality tests — with the facts that actually matter: how many questions, how long it takes, whether it is really free, whether you need an account, and whether you get a 30-facet breakdown.

The Big Five is the personality model most academic research is built on. Unlike 16-type systems it does not sort you into a box: it scores you on five independent dimensions — Openness, Conscientiousness, Extraversion, Agreeableness, Neuroticism.

Out of Service and SimilarMinds use established item sets but do not publish an item count on their landing pages.

## Open-source implementations & item pools

- [rubynor/bigfive-web](https://github.com/rubynor/bigfive-web) (958★) — open-source IPIP-NEO implementation; powers bigfive-test.com
- [Alheimsins/bigfive-web](https://github.com/Alheimsins/bigfive-web) (237★) — earlier IPIP-NEO web implementation, also open source
- [IPIP item pool](https://ipip.ori.org/) — the public-domain International Personality Item Pool; most free Big Five tests are built on items from here

## Related, but not strictly Big Five

- [16Personalities](https://www.16personalities.com/) — a 16-type system framed on Big Five research. Very popular, but it types you instead of scoring five continuous traits, so it is not comparable row-for-row with the tests above.

## How we picked

1. Free to take, and free to see at least your five trait scores — no paywall in front of the basic result.
2. Built on a published item set (IPIP, IPIP-NEO) or documented psychometrics.
3. No account required to start the test.

Sites are ordered by usefulness, not by affiliation. Ocean Test is our own project and is marked "(ours)".
